# Voicemod

Control Voicemod from KnobDeck, on Windows and macOS.

## What it does

- Voice Changer, Hear Myself, Background Effects, Mute Microphone and Mute Sounds for Me toggles
  that follow Voicemod's own state.
- Select Voice keys (lit while their voice is on), Random Voice, and a Favorite Voices wheel.
- Play Sound and Stop All Sounds for the soundboard; hold Bleep to censor yourself.

## Setup

Open Voicemod, then run setup. It connects to Voicemod's Control API with KnobDeck's client key.
If you have your own key from Voicemod, paste it in setup instead.

## How it works

Voicemod's local Control API (a websocket on one of Voicemod's fixed ports) — no keyboard shortcuts.
