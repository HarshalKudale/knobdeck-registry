# Streamlabs Desktop

Control Streamlabs Desktop (formerly Streamlabs OBS) from KnobDeck, on Windows and macOS.

## What it does

- Go Live, Record and Replay Buffer toggles that follow the app's real state, and Save Replay.
- Scene keys that light up while their scene is live.
- Source Visibility, Mute Audio Source and an Audio Source Volume dial/slider (the mixer fader).

## Setup

1. In Streamlabs Desktop open **Settings ▸ Remote Control**, click the QR code, then **Show details**.
2. Copy the **API token** into KnobDeck's setup (keep Streamlabs Desktop open; setup checks the token).

## How it works

Streamlabs Desktop's local API (JSON-RPC over a websocket on port 59650) — no keyboard shortcuts.
